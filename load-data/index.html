Excel multi-onglets · graphe typé · sans build

Importer plusieurs onglets Excel, construire le graphe et exporter le stockage JSON

Chargez un ou plusieurs classeurs, laissez le schéma semi-configuré faire le mapping des onglets, puis exportez un stockage JSON compact pour la future dataviz.

Ce que fait le module
  • Lit plusieurs fichiers Excel et plusieurs onglets
  • Construit un graphe typé en mémoire
  • Préserve les relations hiérarchiques de capacités
  • Exporte un storage-data.json compact pour la page de viz
Sélectionnez un ou plusieurs classeurs. Le moteur lit les valeurs calculées, pas le moteur de formule.

Configuration semi-configurée

Onglets et colonnes à adapter une fois
Ajustez les noms d’onglets et les alias de colonnes si vos classeurs réels diffèrent du modèle par défaut.
