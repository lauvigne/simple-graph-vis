# Marimo notebooks

Arborescence canonique des notebooks:

- `notebooks/reports/` pour les notebooks d'exploitation et de visualisation
- `notebooks/admin/` pour les notebooks de chargement, debug et paramétrage

Les helpers réutilisables des notebooks vivent dans `src/report_helpers/`.

## Lancement

Exemples:

```bash
cd /Users/lauvigne/Documents/New\ project/marimo
./.venv/bin/marimo edit notebooks/reports/app.py
```

```bash
cd /Users/lauvigne/Documents/New\ project/marimo
./.venv/bin/marimo edit notebooks/admin/ingest.py
```
